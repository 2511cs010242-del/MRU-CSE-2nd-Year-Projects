# RezQgo – Smart Disaster Response

**Project Type:** Java, Spring Boot, MySQL, HTML

## Description
RezQgo is a smart disaster response and management application designed to help users access disaster-related information through a web interface.

## Technologies Used
- Java
- Spring Boot
- MySQL
- HTML
- Maven

## Main Features
- User registration and login
- Web-based interface
- Disaster-related data management
